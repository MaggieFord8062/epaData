What the file needs

One row for each facility, unit and year, with a header row naming the columns. Column names can match this site's CSV downloads (like "Facility ID" and "CO2 (tons)") or EPA's own CAMPD names (like "facilityId" and "co2Mass"). Extra columns are ignored. The easiest way to make a valid file is to download one from Search and edit it.
