Why one input can seem to work backwards

Across all units, bigger units have more gross load, more heat input and more operating hours at once. When one of them changes and the others are held fixed, the model is asked about a unit that doesn't exist in the data, such as one making more electricity from the same fuel. Linear regression then answers with the effect it learned across units, which can point the "wrong" way. The "Runs 10% more" scenario, where load, heat input and hours rise together, is the realistic version.
